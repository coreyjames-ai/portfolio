## What was built

A business run by agents needs email, a contact database and a sales pipeline from day one, and the email/CRM provider's API covers nearly three hundred operations. I rebuilt every one of them as a tool of my own behind my gateway. Around them I built the path: identity checks on every caller, the work order worked out from that identity, a durable record of every call, and inbound events routed back to the right team. The provider's credentials never leave my server. This provider does not support stamping work-order tags onto what it creates, so the gateway attributes its calls in its own accounting and leaves the provider's objects untouched.

## What the group covers

Loyalty programs, 50 tools. Agents set up programs, tiers, rewards, balances and vouchers.

Campaigns, 43 tools. Agents create, test, send and report on email, SMS and WhatsApp campaigns, edit email designs and keep the brand assets the campaigns use.

Transactional messaging, 28 tools. Agents send one-to-one email, SMS and WhatsApp messages, manage the templates for them, and read delivery reports, bounces and block lists.

Contacts and CRM, 71 tools. Agents manage contacts, imports and exports, lists, folders, segments and custom attributes, and the CRM side of companies, deals, pipelines, tasks, notes, files and custom object records.

E-commerce, 26 tools. Agents manage products, categories, orders, coupons and payment requests, and read sales attribution by campaign.

Conversations, 9 tools. Agents read and answer live-chat conversations.

Account administration and sending setup, 48 tools. Agents manage sub-accounts, user groups, users and permissions, sender identities, sending domains and dedicated IPs, and check background processes.

Webhooks, events, inbound mail and feeds, 16 tools. Agents register webhooks, track custom events, read inbound email and connect external data feeds.

The breadth here is the provider's. My part means an agent can use any of these tools and every call is still checked, attributed and accounted for.

## What was verified

Each line is a claim the canonical page supports, with the figure as the page states it.

- Governed API integration for AI agents: 291 tools rebuilt from an email and CRM provider's API, letting agent teams run campaigns, transactional messages, contacts, deals and loyalty programs.
