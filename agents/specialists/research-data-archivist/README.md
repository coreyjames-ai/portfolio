## What it does

This agent manages stored research data by version: it lists what is stored, closes and activates versions, releases checkpoints and clears out old versions.

For an AI research lead with large stored result sets.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.
