# Dead Code Finder

**Lists functions and types that nothing appears to call, as candidates for a person to review.**

Canonical: https://coreyjames.ai/agents/specialists/dead-code-finder/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Lists functions and types that nothing appears to call, as candidates for a person to review. It notes that calls across package boundaries can be hidden from the map.

For an engineering manager planning a clean-up.

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.

Group: Code intelligence and team memory.
