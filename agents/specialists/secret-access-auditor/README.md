# Secret Access Auditor

**Lists every stored credential with the roles and machines allowed to use it.**

Canonical: https://coreyjames.ai/agents/specialists/secret-access-auditor/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Lists every stored credential with the roles and machines allowed to use it. The values are never shown.

For a security lead asked who can use which credential.

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.

Group: Security and access.
