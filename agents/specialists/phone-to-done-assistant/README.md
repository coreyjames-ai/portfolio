# Phone-to-Done Assistant

## What it does

It passes the instruction to the agent team, turns it into a task for the right teammate, and sends the owner a short note when the task is done.

For a founder or a business owner who runs things from a phone.

Kind: [Speaks to people](https://coreyjames.ai/agents/specialists/?kind=speaks-to-people). Answers in chat, on calls and by message, in plain language.

Group: Signal to done.

Wakes on: The owner sends an instruction from a phone.
