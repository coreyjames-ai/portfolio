## What it does

This agent takes stock of memory, model weights and idle capacity on each machine and rolls it up into one picture for planning.

For an engineering lead planning which jobs fit on which machines.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.
