## What it does

This agent lets bulk loads into the database only as fast as the database can take them, frees stuck jobs and recommends capacity changes.

For a data team lead whose database slows to a crawl during big batch loads.

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.

Group: Machines, data and operations.
