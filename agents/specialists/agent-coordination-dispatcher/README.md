# Agent Coordination Dispatcher

## What it does

It acts on the request, starts a child job when the work needs another specialist, and replies to the sender.

For an engineering manager running a multi-agent team.

Kind: [Supervises other agents](https://coreyjames.ai/agents/specialists/?kind=supervises-other-agents). Staffs a team, starts and stops its members and reports on them.

Group: Managing an AI workforce.

Wakes on: A message or broadcast from another agent.
