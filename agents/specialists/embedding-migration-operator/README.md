# Embedding Migration Operator

**Rebuilds the search vectors for a whole index or for all engineering notes, in bulk on a GPU or one item at a time on CPU.**

Canonical: https://coreyjames.ai/agents/specialists/embedding-migration-operator/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Rebuilds the search vectors for a whole index or for all engineering notes, in bulk on a GPU or one item at a time on CPU. It warns when the new model's size does not match the stored vectors and reports progress and exact counts throughout.

For a platform lead changing the model that powers search, or rebuilding search after a failure.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.

Group: Code intelligence and team memory.
