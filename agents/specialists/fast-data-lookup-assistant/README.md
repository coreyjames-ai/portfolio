## What it does

This agent answers questions about another app's records from a kept-in-sync copy, so the team gets fast answers and the other app is not overloaded.

For a support desk or sales team that keeps hitting another app's rate limits.

Kind: [Speaks to people](https://coreyjames.ai/agents/specialists/?kind=speaks-to-people). Answers in chat, on calls and by message, in plain language.

Group: Connecting tools and signals.
