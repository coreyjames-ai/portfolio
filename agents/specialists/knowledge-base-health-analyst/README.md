# Knowledge Base Health Analyst

## What it does

This agent scores every topic on dozens of health measures and reports which topics need more depth or rebalancing.

For a knowledge manager who needs to know where the knowledge base is weak.

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.

Group: AI models and performance.
