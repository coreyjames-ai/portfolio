# Candidate Fit Analyst

**Paste in a job description and it tells you, requirement by requirement, whether the candidate's published work covers it, with a link to the page that shows it.**

Canonical: https://coreyjames.ai/agents/specialists/candidate-fit-analyst/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Paste in a job description and it tells you, requirement by requirement, whether the candidate's published work covers it, with a link to the page that shows it. It also lists the gaps plainly.

For a recruiter or a hiring manager.

Kind: [Does the work](https://coreyjames.ai/agents/specialists/?kind=does-the-work). Writes, builds, renders and ships the thing that was asked for.

Group: The public front door.
