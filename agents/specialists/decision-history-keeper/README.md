## What it does

It turns notable actions into entries in the searchable decision history.

For an engineering manager who wants a searchable record of what agents did.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Managing an AI workforce.

Wakes on: An agent action is logged.
