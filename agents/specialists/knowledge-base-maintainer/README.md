## What it does

This agent runs the regular upkeep jobs: screening new entries, rebalancing between related topics, refreshing embeddings and rebuilding the search index.

For a knowledge manager with a large, growing knowledge base.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: AI models and performance.
