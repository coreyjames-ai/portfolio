# Team Knowledge Desk

**Answers questions in team chat from everything that team is allowed to see: the channel's own conversation, files shared there, the codebase, reference documents, libraries, past engineering notes and agent activity.**

## What it does

Answers questions in team chat from everything that team is allowed to see: the channel's own conversation, files shared there, the codebase, reference documents, libraries, past engineering notes and agent activity. Each source is searched and ranked separately and stays inside the team's scope.

For a support desk or project team that works in a shared chat workspace.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
