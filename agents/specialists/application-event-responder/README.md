## What it does

It decides what the event needs, starts that work with the right team member, and checks the result when it comes back.

For a product manager or an engineering manager.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.

Group: Connecting tools and signals.

Wakes on: Any event the business's own software sends, such as a failed import or a cancelled booking.
