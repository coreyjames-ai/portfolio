## What it does

Starting from a conversation about the job, it writes the design, studies the database, designs the work queue, drafts the blueprint and prepares the database. It then writes the settings, logic and documentation, checks the result against the rules and registers the job as a new tool that a person switches on.

For a data engineering lead who needs a new automated data job.

Kind: [Does the work](https://coreyjames.ai/agents/specialists/?kind=does-the-work). Writes, builds, renders and ships the thing that was asked for.

Group: Building software.
