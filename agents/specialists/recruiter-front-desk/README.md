## What it does

When another company's AI agent sends a message, it works out whether the agent wants a fit report, a search, an introduction or a way to get in touch, answers with cited results, and asks for anything that is missing.

For a recruiting firm whose own AI agent does the sourcing.

Kind: [Speaks to people](https://coreyjames.ai/agents/specialists/?kind=speaks-to-people). Answers in chat, on calls and by message, in plain language.
