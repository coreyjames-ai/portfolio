# Recovery Policy Setter

**Sets for each job whether a lost machine is replaced automatically, moved to owned hardware, paused for a decision or allowed to fail, and how much extra price is acceptable.**

## What it does

Sets for each job whether a lost machine is replaced automatically, moved to owned hardware, paused for a decision or allowed to fail, and how much extra price is acceptable.

For an owner who wants a say in what happens when a rented machine is taken away.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.

Group: Machines, data and operations.
