# Self-Starting Job Scheduler

## What it does

This agent turns a job into a standing service that starts itself when work piles up or on a schedule, and lets you list or stop those services at any time.

For a data team lead tired of kicking off jobs by hand.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.

Group: Machines, data and operations.
