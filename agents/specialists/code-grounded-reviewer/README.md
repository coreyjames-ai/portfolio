# Code-Grounded Reviewer

## What it does

Reviews a team's claims about finished work with search access limited to that system's code, so every finding points to a file and line.

For a QA lead who wants reviews checked against the real code rather than against claims.

Kind: [Challenges decisions](https://coreyjames.ai/agents/specialists/?kind=challenges-decisions). Reviews a plan or a result and argues with it before it ships.

Group: Code intelligence and team memory.
