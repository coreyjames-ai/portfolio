## What it does

Rents cloud GPUs only when the day's budget allows, prefers the cheapest current spot price, connects them back to your private network over an outbound link, and hands them back as soon as the work is done or the money runs out. You pay for minutes of real work, not forgotten machines.

For an engineering manager who rents GPUs by the hour.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.
