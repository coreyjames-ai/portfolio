# Knowledge Base Builder

**This agent questions an AI model topic by topic, finds the thin areas, proposes new entries, keeps only the ones that pass a quality bar, and deepens weak topics until the knowledge base is full.**

## What it does

This agent questions an AI model topic by topic, finds the thin areas, proposes new entries, keeps only the ones that pass a quality bar, and deepens weak topics until the knowledge base is full.

For a research lead or knowledge manager who wants an AI model's knowledge written down.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: AI models and performance.
