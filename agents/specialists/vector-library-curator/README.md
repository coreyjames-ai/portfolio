# Vector Library Curator

**Keeps a large searchable collection healthy: it embeds new material, rebuilds and checks the search indexes, scores how well each topic cluster hangs together on the GPU, accepts or rejects new clusters, rebalances crowded ones, and retires stale index files.**

## What it does

Keeps a large searchable collection healthy: it embeds new material, rebuilds and checks the search indexes, scores how well each topic cluster hangs together on the GPU, accepts or rejects new clusters, rebalances crowded ones, and retires stale index files.

For a search or knowledge-management lead with a large vector collection.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: AI models and performance.
