# AI Model Librarian

## What it does

Brings a requested AI model in from its exact source, checks access and the licence question with the owner first, installs it, checks the files are intact and keeps the catalogue of every model and where it came from.

For an IT operations lead.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Machines, data and operations.
