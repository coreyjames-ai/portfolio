## What it does

Files each document against the right deal, company or contact, finds it on request and removes outdated copies.

For a sales team that keeps contracts and proposals with the deal.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.
