# Knowledge Entry Screener

## What it does

Tests each proposed entry against the existing topics and records an accept, hold or reject decision with the measurement behind it.

For a knowledge base owner who wants only entries that belong.

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.

Group: AI models and performance.
