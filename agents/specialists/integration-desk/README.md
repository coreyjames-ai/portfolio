## What it does

It offers every question type as a plain web address with a published description, returns answers as data or as readable text, and supports the standard search-and-fetch pattern that chat assistants use.

For a team that wants to plug the portfolio into its own assistant or tools.

Kind: [Speaks to people](https://coreyjames.ai/agents/specialists/?kind=speaks-to-people). Answers in chat, on calls and by message, in plain language.

Group: Connecting tools and signals.
