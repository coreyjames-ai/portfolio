## What it does

It starts a worker on a local machine or in the cloud, keeps the requester informed of progress, returns the results and files, and shuts the worker down when idle.

For an IT or operations lead whose people work in Microsoft Teams.

Kind: [Does the work](https://coreyjames.ai/agents/specialists/?kind=does-the-work). Writes, builds, renders and ships the thing that was asked for.

Group: Meetings, voice and the AI colleague.

Wakes on: Someone submits a work request from Teams.
