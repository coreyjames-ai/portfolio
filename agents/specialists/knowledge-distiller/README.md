# Knowledge Distiller

Canonical: https://coreyjames.ai/agents/specialists/knowledge-distiller/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Groups similar notes and condenses each group into a single learning. It slims long memory files by compressing low-value sections after backing up the original, writes a recent-activity summary into project folders, and publishes a "what we learned" feed.

For a knowledge manager who wants fewer, better notes.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
