## What it does

This agent picks an image, checks the container settings, runs the job on local or rented GPUs, keeps an eye on it and shuts the container down when it is done.

For an engineering lead who runs heavy jobs on rented or local GPUs.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.

Group: Machines, data and operations.
