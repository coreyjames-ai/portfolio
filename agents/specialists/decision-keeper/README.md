# Decision Keeper

**Writes down every decision, constraint and open question as it is made, so nobody relitigates last month's call and new people can find the reasoning.**

## What it does

Writes down every decision, constraint and open question as it is made, so nobody relitigates last month's call and new people can find the reasoning.

For a leadership team.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Meetings, voice and the AI colleague.
