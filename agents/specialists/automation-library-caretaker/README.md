# Automation Library Caretaker

**This agent keeps the team's library of automated jobs up to date.**

Canonical: https://coreyjames.ai/agents/specialists/automation-library-caretaker/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

This agent keeps the team's library of automated jobs up to date. It updates them when shared code changes, rechecks them, rewrites their documentation and retires the ones nobody uses.

For an engineering manager whose team owns dozens of automated jobs.

Kind: [Does the work](https://coreyjames.ai/agents/specialists/?kind=does-the-work). Writes, builds, renders and ships the thing that was asked for.

Group: Building software.
