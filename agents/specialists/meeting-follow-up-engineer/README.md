# Meeting Follow-up Engineer

**Takes the meeting transcript and pulls out the engineering action items.**

Canonical: https://coreyjames.ai/agents/specialists/meeting-follow-up-engineer/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Takes the meeting transcript and pulls out the engineering action items. For each item it finds where in the code the work would land and how far it reaches, then drafts the task plan.

For an engineering manager coming out of a design or planning meeting.

Kind: [Does the work](https://coreyjames.ai/agents/specialists/?kind=does-the-work). Writes, builds, renders and ships the thing that was asked for.

Group: Code intelligence and team memory.
