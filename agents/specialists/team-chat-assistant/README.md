# Team Chat Assistant

## What it does

It answers in the same thread using the team's shared memory and documents, and creates or updates documents when asked.

For any team that works in a shared chat.

Kind: [Speaks to people](https://coreyjames.ai/agents/specialists/?kind=speaks-to-people). Answers in chat, on calls and by message, in plain language.

Group: Meetings, voice and the AI colleague.

Wakes on: Someone posts a question or request in a channel or thread.
