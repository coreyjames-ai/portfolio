# Failed Machine Recovery Specialist

**Notices when a GPU worker gets sick or goes silent, then moves its work: to a free local card first, then to the same provider at today's price, then to another provider, and otherwise into a waiting line.**

Canonical: https://coreyjames.ai/agents/specialists/failed-machine-recovery-specialist/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Notices when a GPU worker gets sick or goes silent, then moves its work: to a free local card first, then to the same provider at today's price, then to another provider, and otherwise into a waiting line. For jobs you flag, it pauses and asks you first.

For an on-call operations engineer.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.

Group: Machines, data and operations.
