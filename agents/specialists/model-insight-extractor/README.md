# Model Insight Extractor

## What it does

Generates a large set of test prompts, runs them through the model, captures the model's internal state for each prompt, and re-runs any that failed. You get a clean dataset of model internals ready for analysis.

For a research lead studying what a model does inside.

Kind: [Does the work](https://coreyjames.ai/agents/specialists/?kind=does-the-work). Writes, builds, renders and ships the thing that was asked for.
