## What it does

It sets up the connection, issues and rotates its access key, configures the sending system, confirms events arrive, and switches the connection off when it is no longer needed.

For an IT lead or an operations lead connecting a new tool.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.

Group: Connecting tools and signals.

Wakes on: A request to start hearing from a new system.
