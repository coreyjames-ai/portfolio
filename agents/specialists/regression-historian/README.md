# Regression Historian

**Given a broken function or an error, works out which pieces of work touched that area and in what order, who calls it now, and how the failure travels through the code.**

## What it does

Given a broken function or an error, works out which pieces of work touched that area and in what order, who calls it now, and how the failure travels through the code.

For an engineering lead chasing something that used to work.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
