## What it does

Reconstructs what any agent did in a time window: its raw actions, the conversations it took part in and the money it spent, in one audit report.

For a compliance lead who must answer what an agent did and why.

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.

Group: Managing an AI workforce.
