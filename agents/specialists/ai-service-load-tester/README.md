## What it does

This agent runs the model under realistic traffic against a standard setup, checks each memory-saving path and compares runs.

For an AI platform lead about to put a model in front of users.

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.

Group: AI models and performance.
