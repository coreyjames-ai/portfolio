# Index Upkeep Operator

**Keeps every index matching its source.**

Canonical: https://coreyjames.ai/agents/specialists/index-upkeep-operator/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Keeps every index matching its source. It removes code for deleted files off the main path, closes any gap between the database and the fast search cache, reloads the cache after a restart, and lets an operator pause, resume or check scheduled indexing. It also blocks the removal of an index that is still in use.

For a platform or IT operations lead responsible for keeping search accurate.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.

Group: Code intelligence and team memory.
