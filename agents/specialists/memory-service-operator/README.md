## What it does

Looks after the service day to day. It checks status, readiness and logs for each component, restarts or stops a component on request, lists GPUs, checks for signed updates, validates the licence, and issues and checks the access tokens remote agents use. It can also run load and fault tests and report how the service holds up.

For an IT operations lead who runs the knowledge platform.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.

Group: Code intelligence and team memory.
