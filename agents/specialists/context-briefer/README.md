# Context Briefer

**Puts the most relevant past notes and related code in front of the assistant at the moment it needs them.**

Canonical: https://coreyjames.ai/agents/specialists/context-briefer/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Puts the most relevant past notes and related code in front of the assistant at the moment it needs them. It weighs what the session has been working on, ranks the notes, filters out near-duplicates and avoids repeating the same topic on the next step.

For a team using AI coding assistants.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.

Wakes on: A session starting, each question asked, and each file read or edited.
