# Issue Triage Engineer

**Reads each new issue, finds the code most likely at fault and comments the suspect file and line with a triage label so a developer starts in the right place.**

Canonical: https://coreyjames.ai/agents/specialists/issue-triage-engineer/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Reads each new issue, finds the code most likely at fault and comments the suspect file and line with a triage label so a developer starts in the right place.

For a support desk or engineering manager with a growing issue queue.

Kind: [Does the work](https://coreyjames.ai/agents/specialists/?kind=does-the-work). Writes, builds, renders and ships the thing that was asked for.

Group: Building software.
