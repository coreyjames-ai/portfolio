# Shared GPU Traffic Warden

**Lets requests into the small model only when the card has measured free memory, and otherwise answers "busy, try again in this many seconds" instead of crashing the large model.**

## What it does

Lets requests into the small model only when the card has measured free memory, and otherwise answers "busy, try again in this many seconds" instead of crashing the large model.

For a platform engineer running a small helper model beside a large one on the same card.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.

Group: Machines, data and operations.
