# Live Operations Announcer

Canonical: https://coreyjames.ai/agents/specialists/live-operations-announcer/

## What it does

It posts each event to the team in plain words as it happens.

For a team that wants to hear about machine events as they happen.

Kind: [Speaks to people](https://coreyjames.ai/agents/specialists/?kind=speaks-to-people). Answers in chat, on calls and by message, in plain language.

Group: Machines, data and operations.

Wakes on: A worker starts, fails, recovers or shuts down.
