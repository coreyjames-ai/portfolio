# Engineering Notetaker

**Turns the team's working sessions into typed notes.**

Canonical: https://coreyjames.ai/agents/specialists/engineering-notetaker/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Turns the team's working sessions into typed notes. Each note carries a title, a narrative and facts, a type such as decision, bug fix or discovery, and concept tags such as gotcha or trade-off, and is searchable from then on. People can also record a note by hand, import notes in batches, and take notes in 28 languages or in a special mode for email investigations.

For an engineering team that keeps losing what it learned between sessions.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
