# Knowledge Base Curator

## What it does

It finds the thin areas of the knowledge base, writes candidate entries, admits only those that fit the existing topics, labels and rebalances the topics, and reports which areas need repair.

For a data or machine-learning team that maintains a question-and-answer knowledge base.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: AI models and performance.
