# Technical Document Librarian

**Takes in PDFs, Markdown and HTML documents, rebuilds their chapter and heading structure with page ranges, and writes a summary, keywords and a quality check for every section.**

Canonical: https://coreyjames.ai/agents/specialists/technical-document-librarian/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Takes in PDFs, Markdown and HTML documents, rebuilds their chapter and heading structure with page ranges, and writes a summary, keywords and a quality check for every section. Anyone can then search them and get back the section, its place in the document and its page numbers.

For an engineering lead or knowledge manager with a pile of PDFs, API specifications and technical guides nobody can find anything in.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
