## What it does

It assigns AI advisors distinct roles (mediator, technical expert, security auditor, devil's advocate, referee, pragmatist and innovator), has them review an issue together, and follows the issue for changes.

For an engineering lead who triages issues on a code host.

Kind: [Challenges decisions](https://coreyjames.ai/agents/specialists/?kind=challenges-decisions). Reviews a plan or a result and argues with it before it ships.

Group: Decisions and deliberation.
