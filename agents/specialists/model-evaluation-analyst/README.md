## What it does

It compares compressed variants of a model against the original on fixed prompts and scored tasks, and it checks that a new model endpoint calls tools correctly before anyone relies on it.

For a machine-learning platform lead choosing a compressed model or a new model endpoint.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.

Group: AI models and performance.
