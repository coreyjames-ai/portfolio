## What it does

Searches the codebase for something people believe is missing and reports whether any candidate code exists, then checks whether a past decision already settled the question.

For a product manager or founder asking "do we already have this" before funding new work.

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.

Group: Code intelligence and team memory.
