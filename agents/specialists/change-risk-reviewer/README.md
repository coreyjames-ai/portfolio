## What it does

Before a change goes in, this agent works out how risky it is from what it touches, maps everything that depends on it and asks for the matching level of checking.

For an engineering manager who wants risky changes looked at harder.

Kind: [Challenges decisions](https://coreyjames.ai/agents/specialists/?kind=challenges-decisions). Reviews a plan or a result and argues with it before it ships.

Group: Building software.
