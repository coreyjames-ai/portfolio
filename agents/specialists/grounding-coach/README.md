## What it does

Checks whether the task troubleshoots or spans several files and, if so, asks for a file and line reference from code search before work starts.

For an engineering manager who wants work grounded in the real code.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.

Wakes on: A new task being created.
