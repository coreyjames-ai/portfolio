## What it does

Brings a codebase in from a local folder or straight from GitHub or GitLab, recommends which file types to include, splits the code along function and type boundaries for eight languages, and makes it searchable by meaning and by name. It also builds the map of which code calls, imports and implements which.

For an engineering manager adding a new repository, an acquired codebase or an open-source library to what the team can search.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
