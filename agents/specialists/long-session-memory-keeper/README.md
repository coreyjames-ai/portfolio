# Long-Session Memory Keeper

## What it does

Keeps a long session within its memory budget by shrinking older tool output in stages and leaving a pointer that brings the full text back on request. Before the session's memory is condensed, it writes a reflection of where things stand and puts that reflection back at the start of the resumed session.

For a team running long AI-assisted working sessions.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
