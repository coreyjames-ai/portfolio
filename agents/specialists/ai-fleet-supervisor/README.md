# AI Fleet Supervisor

**Watches every running agent across every machine: who is alive, which tool versions they run, and who asked whom for what.**

Canonical: https://coreyjames.ai/agents/specialists/ai-fleet-supervisor/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Watches every running agent across every machine: who is alive, which tool versions they run, and who asked whom for what. It takes work back from agents that go silent and sends you a daily digest.

For an AI operations lead.

Kind: [Supervises other agents](https://coreyjames.ai/agents/specialists/?kind=supervises-other-agents). Staffs a team, starts and stops its members and reports on them.

Group: Managing an AI workforce.
