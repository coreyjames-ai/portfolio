# Reference Library Keeper

**Keeps each document collection fresh on its own schedule by re-reading only files that changed, re-summarising and re-indexing them, and retrying any sections whose summary failed.**

Canonical: https://coreyjames.ai/agents/specialists/reference-library-keeper/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Keeps each document collection fresh on its own schedule by re-reading only files that changed, re-summarising and re-indexing them, and retrying any sections whose summary failed. It also gives a per-document quality summary and reprocesses failed documents on request.

For a knowledge manager who looks after a folder of manuals, specifications and internal guides.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
