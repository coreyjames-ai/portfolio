## What it does

It turns what you want done into a fully specified plan grounded in the real code and project, checks it before anyone begins, records the facts it relied on with two independent checks, and handles approved changes to a plan already under way.

For an engineering manager who wants work specified before it starts.

Kind: [Does the work](https://coreyjames.ai/agents/specialists/?kind=does-the-work). Writes, builds, renders and ships the thing that was asked for.

Group: Building software.
