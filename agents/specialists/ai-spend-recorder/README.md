## What it does

It reads the model usage from the session, removes duplicates, and records the cost against the task it belongs to.

For a finance lead tracking AI cost by task.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.
