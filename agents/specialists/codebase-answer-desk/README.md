# Codebase Answer Desk

**Answers plain-language questions about the team's own code, such as "where do we handle refunds" or "what calls this function", and returns the exact files and lines.**

## What it does

Answers plain-language questions about the team's own code, such as "where do we handle refunds" or "what calls this function", and returns the exact files and lines. It can be narrowed to one folder or a handful of files when the question is about how those pieces work together.

For an engineering manager, a new engineer, or anyone who needs answers about the team's code without interrupting a senior developer.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
