## What it does

This agent pulls together the regression results, accuracy checks, load tests and package review for a new version and writes one go or no-go summary.

For an AI platform lead deciding whether a new version can ship.

Kind: [Challenges decisions](https://coreyjames.ai/agents/specialists/?kind=challenges-decisions). Reviews a plan or a result and argues with it before it ships.
