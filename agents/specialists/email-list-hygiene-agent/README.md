# Email List Hygiene Agent

## What it does

It removes the address from active lists, records why, and keeps a running view of sender health for the team.

For a marketing lead protecting sender reputation.

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.

Group: Email, text and messaging.

Wakes on: A bounce, block, spam complaint or unsubscribe.
