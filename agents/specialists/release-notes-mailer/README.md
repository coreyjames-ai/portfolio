# Release Notes Mailer

**Summarises what changed over a period from the record of completed work and the code it touched, and sends the notes to a subscriber list as an email campaign.**

## What it does

Summarises what changed over a period from the record of completed work and the code it touched, and sends the notes to a subscriber list as an email campaign.

For a product or marketing lead who owes customers release notes.

Kind: [Speaks to people](https://coreyjames.ai/agents/specialists/?kind=speaks-to-people). Answers in chat, on calls and by message, in plain language.

Group: Code intelligence and team memory.
