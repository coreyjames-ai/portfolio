## What it does

Generates the full skeleton of a new processing job so the only thing left to write is the business logic, checks that it builds, waits for a person to approve the restart, runs a harmless test job through it, and opens a merge request.

For an engineering manager who needs a new data-processing job.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.
