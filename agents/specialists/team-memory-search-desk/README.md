# Team Memory Search Desk

**Searches past notes by keyword, by meaning or by both, filtered by project and date.**

Canonical: https://coreyjames.ai/agents/specialists/team-memory-search-desk/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Searches past notes by keyword, by meaning or by both, filtered by project and date. It can go straight to decisions, changes, gotchas, patterns, problems or trade-offs, find past sessions and past questions people asked, and show the timeline around any note.

For anyone on the team asking "have we seen this before".

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
