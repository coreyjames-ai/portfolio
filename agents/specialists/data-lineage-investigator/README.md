## What it does

This agent traces a record back through every job and change that touched it and writes up the answer.

For a data owner or compliance lead who is asked "where did this number come from".

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.

Group: Machines, data and operations.
