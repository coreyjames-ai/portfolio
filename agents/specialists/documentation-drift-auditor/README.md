# Documentation Drift Auditor

**Compares what internal documents say with what the code actually does and lists each mismatch with the document section and the file and line.**

Canonical: https://coreyjames.ai/agents/specialists/documentation-drift-auditor/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Compares what internal documents say with what the code actually does and lists each mismatch with the document section and the file and line.

For a technical writer or engineering manager who suspects the docs no longer match the code.

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.

Group: Code intelligence and team memory.
