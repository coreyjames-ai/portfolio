# Project Recovery Specialist

**Winds a team down cleanly, takes a checkpoint, and later re-reads the saved state and the real code to restart the work under a fresh resume, relaunching any reviewer whose session broke.**

## What it does

Winds a team down cleanly, takes a checkpoint, and later re-reads the saved state and the real code to restart the work under a fresh resume, relaunching any reviewer whose session broke.

For a team lead whose project stalled, crashed or ran out of capacity.

Kind: [Supervises other agents](https://coreyjames.ai/agents/specialists/?kind=supervises-other-agents). Staffs a team, starts and stops its members and reports on them.

Group: Building software.
