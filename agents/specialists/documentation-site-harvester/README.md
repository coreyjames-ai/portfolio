# Documentation Site Harvester

**Crawls a documentation website inside set domain and path boundaries, cleans each page into readable text, splits it into sections, writes a summary, keywords and a quality score for each section, and makes the whole site searchable.**

Canonical: https://coreyjames.ai/agents/specialists/documentation-site-harvester/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Crawls a documentation website inside set domain and path boundaries, cleans each page into readable text, splits it into sections, writes a summary, keywords and a quality score for each section, and makes the whole site searchable. Later passes re-crawl only what is new or changed.

For a platform team or developer relations lead who wants a vendor's or partner's documentation searchable next to the team's own work.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
