## What it does

Finds the overcrowded topics, proposes which entries to move at a cautious, balanced or aggressive setting, and shows the plan as a dry run before anything moves.

For a knowledge base owner with some topics overcrowded and others thin.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.
