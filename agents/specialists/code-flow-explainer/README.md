# Code Flow Explainer

## What it does

Takes a starting point (a file and line, a function name or a plain question), traces how the work flows through the code, and explains it in plain language. The explanation only describes connections that actually exist in the code.

For a product manager, new hire or executive who needs to understand how a part of the system works without reading code.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
