## What it does

Before anyone writes code, finds how the specification, the vendor manual, a library's source or a documentation website handles the problem, and returns cited sections with page numbers or file paths.

For an architect or engineer about to build something that standards, vendor documentation or open libraries already cover.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
