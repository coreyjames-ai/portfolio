# Porting Pattern Scout

## What it does

Finds how a reference library or specification solves a problem and where the team's own code would host the equivalent. It writes up the method so the team can implement it themselves instead of copying outside code.

For an architect adopting a technique from a standard or an open library.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
