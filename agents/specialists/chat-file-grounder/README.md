# Chat File Grounder

**Reads the shared file from a read-only mount and adds it to that team's searchable knowledge without keeping its own copy.**

Canonical: https://coreyjames.ai/agents/specialists/chat-file-grounder/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Reads the shared file from a read-only mount and adds it to that team's searchable knowledge without keeping its own copy.

For a support desk or project team in a chat workspace.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.

Wakes on: A file being shared in a team chat channel.
