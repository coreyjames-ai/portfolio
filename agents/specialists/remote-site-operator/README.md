# Remote Site Operator

## What it does

Joins a new remote machine to the fleet, gives it its own certificates, copies the models across, keeps it reachable without opening any inbound door in the firewall, and retires it cleanly when it is no longer needed. You get remote hardware that behaves like the box under your desk.

For an infrastructure lead with machines in other rooms, offices or rented data centres.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.

Group: Machines, data and operations.
