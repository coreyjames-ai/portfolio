# Session Recorder

**Opens a record when a session starts, captures the questions asked and the answers given, tracks which model was used, and writes a summary when the session ends.**

Canonical: https://coreyjames.ai/agents/specialists/session-recorder/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Opens a record when a session starts, captures the questions asked and the answers given, tracks which model was used, and writes a summary when the session ends. Each session's history can then be browsed.

For a team lead who wants a record of each AI-assisted working session.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
