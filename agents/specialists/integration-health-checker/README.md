## What it does

This agent runs the standard checks across the integration platform so a broken connection is found before a user finds it.

For an IT lead responsible for many app connections.

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.
