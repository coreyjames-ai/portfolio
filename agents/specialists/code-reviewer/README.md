## What it does

Reviews finished code and reports against the plan, lists what is missing, extra or wrong with file and line, freezes the list after the first pass and then checks only the fixes.

For an engineering manager who wants every change reviewed before it counts.

Kind: [Challenges decisions](https://coreyjames.ai/agents/specialists/?kind=challenges-decisions). Reviews a plan or a result and argues with it before it ships.
