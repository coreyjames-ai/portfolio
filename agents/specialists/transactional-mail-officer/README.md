# Transactional Mail Officer

**It sends receipts, confirmations, password and security notices from approved templates.**

Canonical: https://coreyjames.ai/agents/specialists/transactional-mail-officer/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

It sends receipts, confirmations, password and security notices from approved templates. It looks up any single email's content and delivery history when a customer says it never arrived, and it cancels scheduled emails that are no longer needed.

For a product or engineering lead.

Kind: [Speaks to people](https://coreyjames.ai/agents/specialists/?kind=speaks-to-people). Answers in chat, on calls and by message, in plain language.

Group: Email, text and messaging.
