## What it does

It removes silent agents from the roster, updates the list of available machines, and reports fleet status.

For an IT operations lead running many agents.

Kind: [Supervises other agents](https://coreyjames.ai/agents/specialists/?kind=supervises-other-agents). Staffs a team, starts and stops its members and reports on them.

Group: Managing an AI workforce.

Wakes on: An agent misses its heartbeat or a machine fails a membership check.
