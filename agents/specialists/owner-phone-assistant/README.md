# Owner Phone Assistant

**It passes the message to the agent team running the work and sends the team's answers back to the phone.**

Canonical: https://coreyjames.ai/agents/specialists/owner-phone-assistant/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

It passes the message to the agent team running the work and sends the team's answers back to the phone.

For a founder or an owner who is often away from the desk.

Kind: [Speaks to people](https://coreyjames.ai/agents/specialists/?kind=speaks-to-people). Answers in chat, on calls and by message, in plain language.

Group: Meetings, voice and the AI colleague.

Wakes on: The owner sends a message from a phone.
