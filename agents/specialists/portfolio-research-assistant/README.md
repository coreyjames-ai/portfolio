# Portfolio Research Assistant

**It answers questions about a person's body of work with the pages, results and evidence lines that cover each question.**

Canonical: https://coreyjames.ai/agents/specialists/portfolio-research-assistant/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

It answers questions about a person's body of work with the pages, results and evidence lines that cover each question. It can hand back the full text of any page.

For a technical interviewer or a due-diligence analyst.

Kind: [Speaks to people](https://coreyjames.ai/agents/specialists/?kind=speaks-to-people). Answers in chat, on calls and by message, in plain language.

Group: The public front door.
