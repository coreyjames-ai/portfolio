# Write Queue Firefighter

## What it does

Takes the page when the database write queue backs up, follows the recovery procedure, drains the queue if it has to, and confirms that writes are flowing again. You get a short account of what happened instead of a midnight debugging session.

For an on-call operations engineer.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.

Group: Machines, data and operations.
