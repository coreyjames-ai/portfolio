# Secrets and Certificates Officer

**Keeps every credential and certificate in one locked store.**

Canonical: https://coreyjames.ai/agents/specialists/secrets-and-certificates-officer/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Keeps every credential and certificate in one locked store. It rotates them, pushes them to the machines that need them, renews public certificates, issues internal ones, and installs trust into each new container as it starts, and it never shows a secret's value to anyone.

For a security lead.

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.

Group: Security and access.
