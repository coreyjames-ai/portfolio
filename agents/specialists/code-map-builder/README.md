# Code Map Builder

**Builds and maintains the dependency map: calls, imports, implementations, references, definitions and re-exports.**

Canonical: https://coreyjames.ai/agents/specialists/code-map-builder/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Builds and maintains the dependency map: calls, imports, implementations, references, definitions and re-exports. Each call is linked to its definition only when the match is unambiguous, so the map leaves a link open rather than guessing it.

For an architect who needs an accurate map of how a large codebase fits together.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
