# GPU Fleet Manager

**Starts a GPU worker on whichever machine you name, tells you what is running where, and shuts down idle workers with their final cost.**

Canonical: https://coreyjames.ai/agents/specialists/gpu-fleet-manager/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Starts a GPU worker on whichever machine you name, tells you what is running where, and shuts down idle workers with their final cost. You stop tracking which card is busy and which one is wasting power.

For an IT operations lead who runs GPU machines.

Kind: [Runs infrastructure](https://coreyjames.ai/agents/specialists/?kind=runs-infrastructure). Keeps machines, queues and data moving.

Group: Machines, data and operations.
