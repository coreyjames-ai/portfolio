## What it does

It prompts the stalled session to retry its last step so the work continues without a person stepping in.

For an engineering or operations lead.

Kind: [Supervises other agents](https://coreyjames.ai/agents/specialists/?kind=supervises-other-agents). Staffs a team, starts and stops its members and reports on them.

Group: Managing an AI workforce.

Wakes on: An agent session stops because the AI service hit a rate limit.
