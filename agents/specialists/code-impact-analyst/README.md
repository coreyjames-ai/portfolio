# Code Impact Analyst

**For every function or type a change touches, it lists what calls it and what it calls up to three steps out.**

Canonical: https://coreyjames.ai/agents/specialists/code-impact-analyst/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

For every function or type a change touches, it lists what calls it and what it calls up to three steps out. It counts how many files and packages are affected and sorts the change into security, concurrency, data-schema or routine risk from the paths involved, so the reviewer knows how hard to look.

For an engineering manager or reviewer who wants to know what a change will touch before it is made.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
