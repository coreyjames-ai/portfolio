# Decision Recorder

**Watches the team's decisions log and working notes folder.**

Canonical: https://coreyjames.ai/agents/specialists/decision-recorder/  
Author: Corey James · Published: 2026-11-11 · Kind: agent specialist  

## What it does

Watches the team's decisions log and working notes folder. It files each newly agreed decision together with the review it survived, files each checkpoint note, and keeps a log of what it filed.

For a team lead who wants every agreed decision, and every checkpoint, kept where people can find it later.

Kind: [Keeps knowledge](https://coreyjames.ai/agents/specialists/?kind=keeps-knowledge). Records what happened and finds it again when someone asks.

Group: Code intelligence and team memory.
