## What it does

Before new code joins the product, this agent runs the acceptance checks and refuses anything that contains placeholder code or skipped steps.

For an engineering manager who wants nothing half-finished shipped.

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.

Group: Building software.
