# Search Quality Analyst

## What it does

Measures and tunes search quality. It compares the fast search cache against the database baseline, runs side-by-side and smoke tests on fixed question sets, studies usage data with seven groups of model prompts, and recommends setting changes that a person can apply or dismiss.

For a platform lead accountable for whether search finds the right thing.

Kind: [Audits and guards](https://coreyjames.ai/agents/specialists/?kind=audits-and-guards). Checks access, spend and behaviour, and raises the alarm.

Group: Code intelligence and team memory.
