# The Publisher of Record

**For a researcher or consultant with work to put on the record.**

Canonical: https://coreyjames.ai/agents/roles/publisher-of-record/  
Author: Corey James · Published: 2026-11-11 · Kind: agent role  

## The story

The agent publishes the portfolio, deposits research where it receives a permanent identifier and keeps the author's public record current.

## Function

[The public front door](https://coreyjames.ai/agents/functions/the-public-front-door/): How outside people and their assistants find and question the work.

## The crew

The specialists behind this role, grouped by the kind of work they do.

### Does the work

- [Portfolio Publisher](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/portfolio-publisher) · [page](https://coreyjames.ai/agents/specialists/portfolio-publisher/): It turns approved write-ups into a complete website, checks that every figure appears on its own page, renders diagrams and charts, takes desktop and phone screenshots for review, publishes the site, and tells the search engines.
- [Agent Directory Listing Agent](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/agent-directory-listing-agent) · [page](https://coreyjames.ai/agents/specialists/agent-directory-listing-agent/): It lists the agent in a public agent registry and publishes the description files and discovery records that other agents look for, together with a readable text copy of every page.

### Speaks to people

- [Portfolio Research Assistant](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/portfolio-research-assistant) · [page](https://coreyjames.ai/agents/specialists/portfolio-research-assistant/): It answers questions about a person's body of work with the pages, results and evidence lines that cover each question.

### Keeps knowledge

- [Research Archivist](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/research-archivist) · [page](https://coreyjames.ai/agents/specialists/research-archivist/): It publishes a public code repository for each project on two code hosts with a README, a citation file and figures, deposits each project report in a research archive to get a permanent citation identifier, and links both back from every page.

### Audits and guards

- [Answer Quality Steward](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/answer-quality-steward) · [page](https://coreyjames.ai/agents/specialists/answer-quality-steward/): It keeps the judging model running at the edge or on a local graphics card, caps how many judgements are spent each day, falls back to keyword scoring when the model is unavailable, and checks answer quality against a fixed set of reference questions.
- [Asset Origin Auditor](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/asset-origin-auditor) · [page](https://coreyjames.ai/agents/specialists/asset-origin-auditor/): Answers "where did this image come from": which source files, which AI models and which settings produced each published asset, and whether the file is unchanged.
