# The Recruiter's Counterpart

**For a recruiter whose own AI does the sourcing.**

Canonical: https://coreyjames.ai/agents/roles/recruiters-counterpart/  
Author: Corey James · Published: 2026-11-11 · Kind: agent role  

## The story

A recruiter's agent arrives with a job description. The portfolio's agent reads the requirements and answers each one as covered, partly covered or missing, with the page that supports it. It writes the candidate introduction and passes a contact request through. It is listed where other agents look for agents, so it gets found.

## Function

[The public front door](https://coreyjames.ai/agents/functions/the-public-front-door/): How outside people and their assistants find and question the work.

## The crew

The specialists behind this role, grouped by the kind of work they do.

### Does the work

- [Candidate Fit Analyst](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/candidate-fit-analyst) · [page](https://coreyjames.ai/agents/specialists/candidate-fit-analyst/): Paste in a job description and it tells you, requirement by requirement, whether the candidate's published work covers it, with a link to the page that shows it.
- [Agent Directory Listing Agent](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/agent-directory-listing-agent) · [page](https://coreyjames.ai/agents/specialists/agent-directory-listing-agent/): It lists the agent in a public agent registry and publishes the description files and discovery records that other agents look for, together with a readable text copy of every page.

### Speaks to people

- [Portfolio Research Assistant](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/portfolio-research-assistant) · [page](https://coreyjames.ai/agents/specialists/portfolio-research-assistant/): It answers questions about a person's body of work with the pages, results and evidence lines that cover each question.
- [Candidate Introduction Writer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/candidate-introduction-writer) · [page](https://coreyjames.ai/agents/specialists/candidate-introduction-writer/): It writes a one-paragraph introduction of the person for a research, enterprise or GPU audience, citing the pages it draws on and avoiding superlatives.
- [Recruiter Front Desk](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/recruiter-front-desk) · [page](https://coreyjames.ai/agents/specialists/recruiter-front-desk/): When another company's AI agent sends a message, it works out whether the agent wants a fit report, a search, an introduction or a way to get in touch, answers with cited results, and asks for anything that is missing.
- [Contact Desk](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/contact-desk) · [page](https://coreyjames.ai/agents/specialists/contact-desk/): It takes a message from a visitor, a browser assistant or another company's agent and delivers it only when the sender has given their own name and email.
- [Recruiter Concierge](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/recruiter-concierge) · [page](https://coreyjames.ai/agents/specialists/recruiter-concierge/): It takes the role, returns a cited fit report with the gaps, adds a short introduction for the recruiter's client, and passes the recruiter's note on to the candidate.
- [Integration Desk](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/integration-desk) · [page](https://coreyjames.ai/agents/specialists/integration-desk/): It offers every question type as a plain web address with a published description, returns answers as data or as readable text, and supports the standard search-and-fetch pattern that chat assistants use.
