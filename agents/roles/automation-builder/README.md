# The Automation Builder

**For a manager with recurring jobs done by hand.**

Canonical: https://coreyjames.ai/agents/roles/automation-builder/  
Author: Corey James · Published: 2026-11-11 · Kind: agent role  

## The story

The job is described in plain words. A crew of agents designs it, writes it, tests it and registers it to run on a schedule or when a signal arrives. The library of automations is kept in working order as the systems around it change.

## Function

[Engineering](https://coreyjames.ai/agents/functions/engineering/): Planning, building, reviewing and releasing software, with the reasoning kept.

## The crew

The specialists behind this role, grouped by the kind of work they do.

### Does the work

- [Internal Automation Builder](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/internal-automation-builder) · [page](https://coreyjames.ai/agents/specialists/internal-automation-builder/): You describe a recurring data job in plain words, and this agent designs it, sets up the database pieces, writes the code, checks it against the team's rules and switches it on.
- [Internal Tool Builder Crew](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/internal-tool-builder-crew) · [page](https://coreyjames.ai/agents/specialists/internal-tool-builder-crew/): Starting from a conversation about the job, it writes the design, studies the database, designs the work queue, drafts the blueprint and prepares the database.
- [Automation Library Caretaker](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/automation-library-caretaker) · [page](https://coreyjames.ai/agents/specialists/automation-library-caretaker/): This agent keeps the team's library of automated jobs up to date.
- [Software Developer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/software-developer) · [page](https://coreyjames.ai/agents/specialists/software-developer/): Takes one assigned task, reads the brief and the code around it, writes and tests the change inside its allowed folders, submits evidence for each acceptance point and fixes what reviewers send back.

### Runs infrastructure

- [Self-Starting Job Scheduler](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/self-starting-job-scheduler) · [page](https://coreyjames.ai/agents/specialists/self-starting-job-scheduler/): This agent turns a job into a standing service that starts itself when work piles up or on a schedule, and lets you list or stop those services at any time.
- [Data Job Builder](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/data-job-builder) · [page](https://coreyjames.ai/agents/specialists/data-job-builder/): Generates the full skeleton of a new processing job so the only thing left to write is the business logic, checks that it builds, waits for a person to approve the restart, runs a harmless test job through it, and opens a merge request.
- [Job Dispatcher](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/job-dispatcher) · [page](https://coreyjames.ai/agents/specialists/job-dispatcher/): This agent starts, follows and recovers processing jobs across every automated job the team owns, and reports their status on request.
- [Service Function Builder](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/service-function-builder) · [page](https://coreyjames.ai/agents/specialists/service-function-builder/): Plans a new data-processing function, prepares its database work queue, generates its files, registers it as a tool and runs a harmless smoke test through it.

### Audits and guards

- [Acceptance Tester](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/acceptance-tester) · [page](https://coreyjames.ai/agents/specialists/acceptance-tester/): Before new code joins the product, this agent runs the acceptance checks and refuses anything that contains placeholder code or skipped steps.
- [Existing-Capability Checker](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/existing-capability-checker) · [page](https://coreyjames.ai/agents/specialists/existing-capability-checker/): Searches the codebase for something people believe is missing and reports whether any candidate code exists, then checks whether a past decision already settled the question.
