# The Company Librarian

**For a team whose knowledge is scattered.**

Canonical: https://coreyjames.ai/agents/roles/company-librarian/  
Author: Corey James · Published: 2026-11-11 · Kind: agent role  

## The story

Files dropped in chat, manuals, specifications and outside documentation all go into one library the agent keeps current. Anyone can ask a question in chat and get an answer with its source. When a plan no longer matches what was built, the agent rewrites the document and keeps the old version.

## Function

[Meetings and teamwork](https://coreyjames.ai/agents/functions/meetings-and-teamwork/): Agents that sit in the meeting, speak, present and follow through.

## The crew

The specialists behind this role, grouped by the kind of work they do.

### Speaks to people

- [New Hire Guide](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/new-hire-guide) · [page](https://coreyjames.ai/agents/specialists/new-hire-guide/): Walks a new team member through the team's shared files and recent decisions, by voice or chat, and leaves them an orientation document to come back to.

### Keeps knowledge

- [Team File Librarian](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/team-file-librarian) · [page](https://coreyjames.ai/agents/specialists/team-file-librarian/): Finds the file someone is talking about, says what it is and whether it is searchable yet, and answers questions about what is inside it.
- [Technical Document Librarian](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/technical-document-librarian) · [page](https://coreyjames.ai/agents/specialists/technical-document-librarian/): Takes in PDFs, Markdown and HTML documents, rebuilds their chapter and heading structure with page ranges, and writes a summary, keywords and a quality check for every section.
- [Documentation Site Harvester](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/documentation-site-harvester) · [page](https://coreyjames.ai/agents/specialists/documentation-site-harvester/): Crawls a documentation website inside set domain and path boundaries, cleans each page into readable text, splits it into sections, writes a summary, keywords and a quality score for each section, and makes the whole site searchable.
- [Reference Library Keeper](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/reference-library-keeper) · [page](https://coreyjames.ai/agents/specialists/reference-library-keeper/): Keeps each document collection fresh on its own schedule by re-reading only files that changed, re-summarising and re-indexing them, and retrying any sections whose summary failed.
- [Team Knowledge Desk](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/team-knowledge-desk) · [page](https://coreyjames.ai/agents/specialists/team-knowledge-desk/): Answers questions in team chat from everything that team is allowed to see: the channel's own conversation, files shared there, the codebase, reference documents, libraries, past engineering notes and agent activity.
- [Out-of-Date Document Fixer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/out-of-date-document-fixer) · [page](https://coreyjames.ai/agents/specialists/out-of-date-document-fixer/): Spots plans that newer decisions have overtaken, publishes a corrected version of each, and tells the owner what changed.
- [Chat File Grounder](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/chat-file-grounder) · [page](https://coreyjames.ai/agents/specialists/chat-file-grounder/): Reads the shared file from a read-only mount and adds it to that team's searchable knowledge without keeping its own copy.
