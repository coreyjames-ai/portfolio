# The Institutional Memory

**For a team that keeps relearning what it already knew.**

Canonical: https://coreyjames.ai/agents/roles/institutional-memory/  
Author: Corey James · Published: 2026-11-11 · Kind: agent role  

## The story

The agent takes notes on every working session, records each decision and distils them over time. Anyone can ask "have we seen this before?" and get the earlier answer. Every AI worker starts its day already briefed on what the team knows.

## Function

[Knowledge and memory](https://coreyjames.ai/agents/functions/knowledge-and-memory/): What the team learned, kept searchable and handed to every new worker.

## The crew

The specialists behind this role, grouped by the kind of work they do.

### Keeps knowledge

- [Engineering Notetaker](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/engineering-notetaker) · [page](https://coreyjames.ai/agents/specialists/engineering-notetaker/): Turns the team's working sessions into typed notes.
- [Session Recorder](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/session-recorder) · [page](https://coreyjames.ai/agents/specialists/session-recorder/): Opens a record when a session starts, captures the questions asked and the answers given, tracks which model was used, and writes a summary when the session ends.
- [Decision Recorder](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/decision-recorder) · [page](https://coreyjames.ai/agents/specialists/decision-recorder/): Watches the team's decisions log and working notes folder.
- [Knowledge Distiller](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/knowledge-distiller) · [page](https://coreyjames.ai/agents/specialists/knowledge-distiller/): Groups similar notes and condenses each group into a single learning.
- [Team Memory Search Desk](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/team-memory-search-desk) · [page](https://coreyjames.ai/agents/specialists/team-memory-search-desk/): Searches past notes by keyword, by meaning or by both, filtered by project and date.
- [Context Briefer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/context-briefer) · [page](https://coreyjames.ai/agents/specialists/context-briefer/): Puts the most relevant past notes and related code in front of the assistant at the moment it needs them.
- [Long-Session Memory Keeper](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/long-session-memory-keeper) · [page](https://coreyjames.ai/agents/specialists/long-session-memory-keeper/): Keeps a long session within its memory budget by shrinking older tool output in stages and leaving a pointer that brings the full text back on request.
- [Note Queue Reconciler](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/note-queue-reconciler) · [page](https://coreyjames.ai/agents/specialists/note-queue-reconciler/): Checks that every queued note reached storage, flags stragglers past a grace period, and records a summary.
- [Agent Activity Historian](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/agent-activity-historian) · [page](https://coreyjames.ai/agents/specialists/agent-activity-historian/): Turns what agents did into searchable notes, so that tool errors become lessons and approvals become recorded decisions.
