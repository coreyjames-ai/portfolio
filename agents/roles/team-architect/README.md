# The Team Architect

**For a founder who wants a set of specialist assistants built around the company's own material.**

Canonical: https://coreyjames.ai/agents/roles/team-architect/  
Author: Corey James · Published: 2026-11-11 · Kind: agent role  

## The story

The founder gives a goal and points at the source material. The agent explores it, proposes a roster of specialists and writes each one's guide. A person reviews the roster before anything starts. New tools are tested with normal and hostile cases before the specialists can use them, and each specialist can ask for the right tool in plain words.

## Function

[AI and model teams](https://coreyjames.ai/agents/functions/ai-and-model-teams/): Launching, tuning and supervising models and the agents that use them.

## The crew

The specialists behind this role, grouped by the kind of work they do.

### Does the work

- [Long-Running Operations Planner](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/long-running-operations-planner) · [page](https://coreyjames.ai/agents/specialists/long-running-operations-planner/): Sets up a standing operation with open-ended responsibilities, a roster of specialists who start only when needed, and a lead who starts first.
- [Internal Tool Builder Crew](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/internal-tool-builder-crew) · [page](https://coreyjames.ai/agents/specialists/internal-tool-builder-crew/): Starting from a conversation about the job, it writes the design, studies the database, designs the work queue, drafts the blueprint and prepares the database.

### Speaks to people

- [Tool Concierge](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/tool-concierge) · [page](https://coreyjames.ai/agents/specialists/tool-concierge/): Takes a plain-language need and returns the best-matching tools from a catalog of hundreds in one answer.

### Supervises other agents

- [Agent Team Designer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/agent-team-designer) · [page](https://coreyjames.ai/agents/specialists/agent-team-designer/): Takes a project's goal and its source material, explores that material through the search tools, proposes a roster of specialist agents, and writes their skill guides and agent definitions.
- [Agent Workforce Provisioner](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/agent-workforce-provisioner) · [page](https://coreyjames.ai/agents/specialists/agent-workforce-provisioner/): Starts agents from role definitions in locked-down containers, pauses, resumes or stops them, and reloads the role and tool catalogs when they change.
- [Team Staffing Coordinator](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/team-staffing-coordinator) · [page](https://coreyjames.ai/agents/specialists/team-staffing-coordinator/): Assembles a mixed team from different model families, gives each role its tool access, replaces anyone who drops out with their history intact and winds the team down at the end.

### Keeps knowledge

- [Session Briefer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/session-briefer) · [page](https://coreyjames.ai/agents/specialists/session-briefer/): It briefs the agent on the current goal and the state of the project before any work begins.

### Runs infrastructure

- [Tool Onboarding Specialist](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/tool-onboarding-specialist) · [page](https://coreyjames.ai/agents/specialists/tool-onboarding-specialist/): Qualifies each new tool with normal and hostile test cases, rebuilds the tool index the agents search, and confirms agents can find the new tool.
- [New App Integration Engineer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/new-app-integration-engineer) · [page](https://coreyjames.ai/agents/specialists/new-app-integration-engineer/): This agent reads a new app's API documentation, generates the tools to use it, tries it with safe read-only test calls, writes the connection settings, stores the credentials and runs the standard checks before the app goes live.

### Audits and guards

- [New Agent Pre-flight Inspector](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/new-agent-pre-flight-inspector) · [page](https://coreyjames.ai/agents/specialists/new-agent-pre-flight-inspector/): Checks a new agent's identity, access and workspace before it joins the team, and refuses the start when something does not match.
