# The Onboarding Buddy

**For a manager onboarding someone.**

Canonical: https://coreyjames.ai/agents/roles/onboarding-buddy/  
Author: Corey James · Published: 2026-11-11 · Kind: agent role  

## The story

The new person asks how the system works and the agent explains it in plain language, with the path through the code behind every statement. It can say why a part was built the way it was and what was tried before. The first week comes with a reading list and someone to ask at any hour, by text or by voice.

## Function

[Meetings and teamwork](https://coreyjames.ai/agents/functions/meetings-and-teamwork/): Agents that sit in the meeting, speak, present and follow through.

## The crew

The specialists behind this role, grouped by the kind of work they do.

### Speaks to people

- [New Hire Guide](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/new-hire-guide) · [page](https://coreyjames.ai/agents/specialists/new-hire-guide/): Walks a new team member through the team's shared files and recent decisions, by voice or chat, and leaves them an orientation document to come back to.
- [Codebase Onboarding Guide](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/codebase-onboarding-guide) · [page](https://coreyjames.ai/agents/specialists/codebase-onboarding-guide/): Answers a newcomer's questions about how the code works with the exact files and lines involved, plus the reference documents and past decisions behind them.
- [Hands-Free Office Assistant](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/hands-free-office-assistant) · [page](https://coreyjames.ai/agents/specialists/hands-free-office-assistant/): Takes spoken requests at the desk speakerphone, answers quick questions aloud, and hands longer jobs, such as building a presentation, to a background worker while showing progress in the team chat.

### Keeps knowledge

- [Code Flow Explainer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/code-flow-explainer) · [page](https://coreyjames.ai/agents/specialists/code-flow-explainer/): Takes a starting point (a file and line, a function name or a plain question), traces how the work flows through the code, and explains it in plain language.
- [System Historian](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/system-historian) · [page](https://coreyjames.ai/agents/specialists/system-historian/): Reconstructs a system's story, covering the decisions that shaped it, the changes made, the problems hit and how each was fixed, and the trade-offs accepted, in time order.
- [Project Reference Librarian](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/project-reference-librarian) · [page](https://coreyjames.ai/agents/specialists/project-reference-librarian/): It answers questions from the reference documents that belong to one project, with page numbers, and ignores documents from other projects.

### Audits and guards

- [Marketing Team Access Manager](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/marketing-team-access-manager) · [page](https://coreyjames.ai/agents/specialists/marketing-team-access-manager/): It invites colleagues to the email and messaging account, gives each the permissions their job needs, and removes access when someone leaves.
