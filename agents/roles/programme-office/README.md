# The Programme Office

**For a programme manager with several projects in flight.**

Canonical: https://coreyjames.ai/agents/roles/programme-office/  
Author: Corey James · Published: 2026-11-11 · Kind: agent role  

## The story

The agent watches each project and wakes when something changes: a review fails, a team stalls, a requirement shifts. It assigns the fix, replans what the change affects and keeps the owner informed by phone. A project closes only when every item has been checked against what was asked for.

## Function

[Engineering](https://coreyjames.ai/agents/functions/engineering/): Planning, building, reviewing and releasing software, with the reasoning kept.

## The crew

The specialists behind this role, grouped by the kind of work they do.

### Does the work

- [Scope Change Manager](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/scope-change-manager) · [page](https://coreyjames.ai/agents/specialists/scope-change-manager/): Handles a mid-project change from proposal to approval: it maps what the change touches, gets an architect's proposal, an independent ruling and a hostile second look, then folds the approved change into the live plan.
- [Project Closer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/project-closer) · [page](https://coreyjames.ai/agents/specialists/project-closer/): Closes a project, phase or program only when every required item carries a current sign-off, writes the closing summary with cost, archives the team and retires everything it opened.
- [Project Workspace Organiser](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/project-workspace-organiser) · [page](https://coreyjames.ai/agents/specialists/project-workspace-organiser/): It mirrors the company's programmes, projects and tasks into the chat sidebar, onboards several projects in one step, and ties each project to its folders and code repositories so that every AI colleague works in the right place.

### Speaks to people

- [Owner Phone Assistant](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/owner-phone-assistant) · [page](https://coreyjames.ai/agents/specialists/owner-phone-assistant/): It passes the message to the agent team running the work and sends the team's answers back to the phone.

### Supervises other agents

- [Delivery Manager](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/delivery-manager) · [page](https://coreyjames.ai/agents/specialists/delivery-manager/): It moves the project to its next step, sends finished work for review, and closes the project when every acceptance criterion is met.
- [Engineering Team Lead](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/engineering-team-lead) · [page](https://coreyjames.ai/agents/specialists/engineering-team-lead/): Runs the whole team through the project: hands out ready work, relays review findings, applies each next step and keeps everyone pointed at the finish line.
- [Close-out and Pause Coordinator](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/close-out-and-pause-coordinator) · [page](https://coreyjames.ai/agents/specialists/close-out-and-pause-coordinator/): It briefs you on where work stands after a break, checks the final evidence before closing a task, phase or project, pauses a team cleanly without losing work, and restarts a stuck worker.
- [Quality Fix Coordinator](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/quality-fix-coordinator) · [page](https://coreyjames.ai/agents/specialists/quality-fix-coordinator/): It records what must be fixed against each failed criterion, assigns the fix, and sends the work back for review.
- [Project Recovery Specialist](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/project-recovery-specialist) · [page](https://coreyjames.ai/agents/specialists/project-recovery-specialist/): Winds a team down cleanly, takes a checkpoint, and later re-reads the saved state and the real code to restart the work under a fresh resume, relaunching any reviewer whose session broke.

### Challenges decisions

- [Task Results Reviewer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/task-results-reviewer) · [page](https://coreyjames.ai/agents/specialists/task-results-reviewer/): It checks the result, marks the task complete or cancelled, and starts the next task in line.
- [Delivery Review Presenter](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/delivery-review-presenter) · [page](https://coreyjames.ai/agents/specialists/delivery-review-presenter/): Joins the review meeting, shares and walks through the project's closing summary, raises a hand for questions and posts the summary in the chat.
- [Decision Desk](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/decision-desk) · [page](https://coreyjames.ai/agents/specialists/decision-desk/): Rules on questions within the authority the founder delegated, writes each ruling down, saves the rest as questions for the founder, and holds any action that needs approval until the approval arrives.
