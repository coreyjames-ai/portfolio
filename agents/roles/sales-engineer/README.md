# The Sales Engineer

**For a sales team with more demos than engineers.**

Canonical: https://coreyjames.ai/agents/roles/sales-engineer/  
Author: Corey James · Published: 2026-11-11 · Kind: agent role  

## The story

The agent joins the customer call, presents the deck and shares its screen for a live demo. When the customer asks a technical question, it answers aloud from the product's own code and documentation. After the call it sends the recap, updates the deal with what was promised and opens a request for anything the product cannot do yet.

## Function

[Sales and customers](https://coreyjames.ai/agents/functions/sales-and-customers/): Inquiries, deals, orders, payments and support, kept moving after the first reply.

## The crew

The specialists behind this role, grouped by the kind of work they do.

### Does the work

- [Sales Pipeline Manager](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/sales-pipeline-manager) · [page](https://coreyjames.ai/agents/specialists/sales-pipeline-manager/): It keeps every deal in the right stage of the right pipeline, links deals to the people and companies involved, imports deals from other tools, and reports the pipeline.
- [Issue Triage Engineer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/issue-triage-engineer) · [page](https://coreyjames.ai/agents/specialists/issue-triage-engineer/): Reads each new issue, finds the code most likely at fault and comments the suspect file and line with a triage label so a developer starts in the right place.
- [Product Demo Clip Maker](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/product-demo-clip-maker) · [page](https://coreyjames.ai/agents/specialists/product-demo-clip-maker/): Records a terminal or product session, masks addresses and private details, paces it and returns a captioned demo clip ready to post.

### Speaks to people

- [Meeting Participant](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/meeting-participant) · [page](https://coreyjames.ai/agents/specialists/meeting-participant/): It listens, answers aloud, takes on tasks, raises its hand when a result is ready, and shows its work on screen or in a presentation.
- [Slide Presenter](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/slide-presenter) · [page](https://coreyjames.ai/agents/specialists/slide-presenter/): Turns a written project document into a slide deck, presents it in the meeting, moves through the slides as it talks, and shares the deck once the meeting is over.
- [Live Demo Presenter](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/live-demo-presenter) · [page](https://coreyjames.ai/agents/specialists/live-demo-presenter/): Runs a live walkthrough in a video meeting, sharing a browser and a terminal, typing as people watch, and explaining each step aloud.
- [Meeting Recap Sender](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/meeting-recap-sender) · [page](https://coreyjames.ai/agents/specialists/meeting-recap-sender/): Sends each attendee a personal recap after the meeting, covering what was decided, what they own, and where to find the recording.
- [Meeting Scheduler](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/meeting-scheduler) · [page](https://coreyjames.ai/agents/specialists/meeting-scheduler/): Books the meeting with a clear purpose and agenda, makes sure it will be recorded and transcribed, and shows up when it starts.

### Keeps knowledge

- [Codebase Answer Desk](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/codebase-answer-desk) · [page](https://coreyjames.ai/agents/specialists/codebase-answer-desk/): Answers plain-language questions about the team's own code, such as "where do we handle refunds" or "what calls this function", and returns the exact files and lines.
- [Reference Researcher](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/reference-researcher) · [page](https://coreyjames.ai/agents/specialists/reference-researcher/): Before anyone writes code, finds how the specification, the vendor manual, a library's source or a documentation website handles the problem, and returns cited sections with page numbers or file paths.
