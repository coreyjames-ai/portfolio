# The Research Desk

**For anyone with a question that needs digging.**

Canonical: https://coreyjames.ai/agents/roles/research-desk/  
Author: Corey James · Published: 2026-11-11 · Kind: agent role  

## The story

The agent reads the relevant files, harvests the documentation sites and visits the pages a signed-in browser can reach. It recalls related work the team did before. The answer comes back as a structured summary with its sources, and as a document when the question was large.

## Function

[Engineering](https://coreyjames.ai/agents/functions/engineering/): Planning, building, reviewing and releasing software, with the reasoning kept.

## The crew

The specialists behind this role, grouped by the kind of work they do.

### Does the work

- [Research Assistant](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/research-assistant) · [page](https://coreyjames.ai/agents/specialists/research-assistant/): Finds and reads the relevant files and web pages, searches them, recalls related past work and returns a structured summary.
- [Browser Research Assistant](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/browser-research-assistant) · [page](https://coreyjames.ai/agents/specialists/browser-research-assistant/): It does approved research in a real signed-in browser, reading and collecting the pages it is asked for.
- [Document Writer and Editor](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/document-writer-and-editor) · [page](https://coreyjames.ai/agents/specialists/document-writer-and-editor/): Drafts a plan, checklist or report in the team chat, revises it when asked, keeps every earlier version, and retires documents that are out of date.

### Supervises other agents

- [Feasibility Study Coordinator](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/feasibility-study-coordinator) · [page](https://coreyjames.ai/agents/specialists/feasibility-study-coordinator/): It chairs a panel, sends temporary investigators off on side questions, reconciles what they bring back, writes up the questions that need the owner's answer, and drafts a synthesis for the panel to vote on.

### Keeps knowledge

- [Reference Researcher](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/reference-researcher) · [page](https://coreyjames.ai/agents/specialists/reference-researcher/): Before anyone writes code, finds how the specification, the vendor manual, a library's source or a documentation website handles the problem, and returns cited sections with page numbers or file paths.
- [Technical Due-diligence Researcher](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/technical-due-diligence-researcher) · [page](https://coreyjames.ai/agents/specialists/technical-due-diligence-researcher/): It surveys a large codebase without changing it and writes structured findings, a source list, open questions and an area report for each part of the estate.
- [Documentation Site Harvester](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/documentation-site-harvester) · [page](https://coreyjames.ai/agents/specialists/documentation-site-harvester/): Crawls a documentation website inside set domain and path boundaries, cleans each page into readable text, splits it into sections, writes a summary, keywords and a quality score for each section, and makes the whole site searchable.
- [Technical Document Librarian](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/technical-document-librarian) · [page](https://coreyjames.ai/agents/specialists/technical-document-librarian/): Takes in PDFs, Markdown and HTML documents, rebuilds their chapter and heading structure with page ranges, and writes a summary, keywords and a quality check for every section.
- [Third-Party Integration Researcher](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/third-party-integration-researcher) · [page](https://coreyjames.ai/agents/specialists/third-party-integration-researcher/): Reads the outside platform's documentation and development-kit source, compares it with the current code and writes down the facts the developers will build on.
