# The Pocket Operator

**For an owner who runs the business from a phone.**

Canonical: https://coreyjames.ai/agents/roles/pocket-operator/  
Author: Corey James · Published: 2026-11-11 · Kind: agent role  

## The story

A text message is enough to start work. The agent turns the request into a plan, puts a team on it and sends progress to the owner's phone. When it reaches a choice only the owner can make, it asks by text or email and waits for the answer. The finished result comes back the way the request went out.

## Function

[Running the company](https://coreyjames.ai/agents/functions/running-the-company/): The owner's side of the business: meetings, decisions, briefings and the work that follows them.

## The crew

The specialists behind this role, grouped by the kind of work they do.

### Does the work

- [Project Planner](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/project-planner) · [page](https://coreyjames.ai/agents/specialists/project-planner/): Turns a goal into a scoped project plan with acceptance criteria, a task breakdown, who may change which files and a staffed team, and hands it back for one yes or no.
- [Plan-to-project Packager](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/plan-to-project-packager) · [page](https://coreyjames.ai/agents/specialists/plan-to-project-packager/): It takes an agreed decision back to the same panel and turns it into a complete implementation plan, a structured project definition and a briefing deck in web and slide form, checks them for consistency, and leaves the go-ahead to the owner.
- [Software Delivery Crew](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/software-delivery-crew) · [page](https://coreyjames.ai/agents/specialists/software-delivery-crew/): This crew of five takes a plan and turns it into working code: a planner writes the tasks, a builder writes the code, a reviewer reads every critical path, a researcher answers "what else does this touch", and an inspector checks the finished work before it is accepted.
- [Idea-to-Approved-Plan Agent](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/idea-to-approved-plan-agent) · [page](https://coreyjames.ai/agents/specialists/idea-to-approved-plan-agent/): It runs a planning debate across several AI models, asks the owner to settle the open questions, and after the owner approves, starts a team on the plan.

### Speaks to people

- [Owner Phone Assistant](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/owner-phone-assistant) · [page](https://coreyjames.ai/agents/specialists/owner-phone-assistant/): It passes the message to the agent team running the work and sends the team's answers back to the phone.
- [Phone-to-Done Assistant](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/phone-to-done-assistant) · [page](https://coreyjames.ai/agents/specialists/phone-to-done-assistant/): It passes the instruction to the agent team, turns it into a task for the right teammate, and sends the owner a short note when the task is done.
- [Ask the Owner by Email Agent](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/ask-the-owner-by-email-agent) · [page](https://coreyjames.ai/agents/specialists/ask-the-owner-by-email-agent/): It emails the owner the question with options, waits for the reply at the team's own address, and continues the work with the answer.
- [Project Status Reporter](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/project-status-reporter) · [page](https://coreyjames.ai/agents/specialists/project-status-reporter/): Reads where each project stands and gives a short spoken update in the meeting, with a written version in the meeting chat.

### Supervises other agents

- [AI Team Dispatcher](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/ai-team-dispatcher) · [page](https://coreyjames.ai/agents/specialists/ai-team-dispatcher/): Starts an AI agent for each role you need, each with its own limited access, workspace and budget, on the machine you choose.
- [Delivery Manager](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/delivery-manager) · [page](https://coreyjames.ai/agents/specialists/delivery-manager/): It moves the project to its next step, sends finished work for review, and closes the project when every acceptance criterion is met.
