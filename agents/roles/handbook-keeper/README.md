# The Handbook Keeper

**For an operations lead whose team runs on a written playbook.**

Canonical: https://coreyjames.ai/agents/roles/handbook-keeper/  
Author: Corey James · Published: 2026-11-11 · Kind: agent role  

## The story

The agent reads the whole handbook and every automated routine, and finds the rules nobody enforces. It compares the documents with what the code does and rewrites the ones that have drifted, keeping the old versions. Every worker, human or AI, starts a session briefed on the current rules.

## Function

[Engineering](https://coreyjames.ai/agents/functions/engineering/): Planning, building, reviewing and releasing software, with the reasoning kept.
