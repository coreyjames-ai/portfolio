# The Assistant-Ready Website

**For a business whose visitors arrive with an AI assistant of their own.**

Canonical: https://coreyjames.ai/agents/roles/assistant-ready-website/  
Author: Corey James · Published: 2026-11-11 · Kind: agent role  

## The story

On every page the site offers the visitor's assistant ready-made actions: search, summarise this page, check a fit, send a message to the owner. Companies that want to connect their own assistant get each question type as a plain web address with a published description. The agent checks the quality of the answers it gives and keeps the site listed where other agents look.

## Function

[The public front door](https://coreyjames.ai/agents/functions/the-public-front-door/): How outside people and their assistants find and question the work.

## The crew

The specialists behind this role, grouped by the kind of work they do.

### Does the work

- [Agent Directory Listing Agent](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/agent-directory-listing-agent) · [page](https://coreyjames.ai/agents/specialists/agent-directory-listing-agent/): It lists the agent in a public agent registry and publishes the description files and discovery records that other agents look for, together with a readable text copy of every page.

### Speaks to people

- [Website Visitor Assistant](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/website-visitor-assistant) · [page](https://coreyjames.ai/agents/specialists/website-visitor-assistant/): On any page of the site it gives the visitor's assistant ready-made actions for a fit report, a search, a page summary, an introduction and a message to the owner.
- [Integration Desk](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/integration-desk) · [page](https://coreyjames.ai/agents/specialists/integration-desk/): It offers every question type as a plain web address with a published description, returns answers as data or as readable text, and supports the standard search-and-fetch pattern that chat assistants use.
- [Contact Desk](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/contact-desk) · [page](https://coreyjames.ai/agents/specialists/contact-desk/): It takes a message from a visitor, a browser assistant or another company's agent and delivers it only when the sender has given their own name and email.
- [Recruiter Front Desk](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/recruiter-front-desk) · [page](https://coreyjames.ai/agents/specialists/recruiter-front-desk/): When another company's AI agent sends a message, it works out whether the agent wants a fit report, a search, an introduction or a way to get in touch, answers with cited results, and asks for anything that is missing.

### Runs infrastructure

- [Integration Wiring Engineer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/integration-wiring-engineer) · [page](https://coreyjames.ai/agents/specialists/integration-wiring-engineer/): Registers each incoming feed, wires the website, email route and provider inbox to the right project, checks that events arrive and reach the lead, and rotates credentials on schedule.

### Audits and guards

- [Answer Quality Steward](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/answer-quality-steward) · [page](https://coreyjames.ai/agents/specialists/answer-quality-steward/): It keeps the judging model running at the edge or on a local graphics card, caps how many judgements are spent each day, falls back to keyword scoring when the model is unavailable, and checks answer quality against a fixed set of reference questions.
- [AI Access Desk](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/ai-access-desk) · [page](https://coreyjames.ai/agents/specialists/ai-access-desk/): Registers each AI assistant as an app, holds every grant until a person approves it, accepts sign-in tokens from your own server and from your workplace platform, shows each assistant only the tools it is allowed, and ties every action to the assignment rather than to what the assistant claims.
- [Sign-in and Token Manager](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/sign-in-and-token-manager) · [page](https://coreyjames.ai/agents/specialists/sign-in-and-token-manager/): This agent handles sign-in codes, access tokens and refresh tokens end to end and keeps the site's security certificate renewed.
