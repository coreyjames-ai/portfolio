# Knowledge and memory

**What the team learned, kept searchable and handed to every new worker.**

Canonical: https://coreyjames.ai/agents/functions/knowledge-and-memory/  
Author: Corey James · Published: 2026-11-11 · Kind: agent function  

## The roles

- [The Institutional Memory](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/institutional-memory) · [page](https://coreyjames.ai/agents/roles/institutional-memory/): For a team that keeps relearning what it already knew.
- [The Code Guide](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/code-guide) · [page](https://coreyjames.ai/agents/roles/code-guide/): For anyone with a question about the code.
- [The Search Keeper](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/search-keeper) · [page](https://coreyjames.ai/agents/roles/search-keeper/): For a platform lead whose company relies on searching its own code and documents.
- [The Search Auditor](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/search-auditor) · [page](https://coreyjames.ai/agents/roles/search-auditor/): For a manager asking whether the company's memory is earning its keep.
- [The Knowledge Gardener](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/knowledge-gardener) · [page](https://coreyjames.ai/agents/roles/knowledge-gardener/): For the owner of a large knowledge base that grows every day.

## Specialists these roles share

- [Commit-Triggered Re-Indexer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/commit-triggered-re-indexer) · [page](https://coreyjames.ai/agents/specialists/commit-triggered-re-indexer/): Starts a re-index of the affected codebase as soon as new code lands and reports progress to the team lead's inbox.
- [Embedding Migration Operator](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/embedding-migration-operator) · [page](https://coreyjames.ai/agents/specialists/embedding-migration-operator/): Rebuilds the search vectors for a whole index or for all engineering notes, in bulk on a GPU or one item at a time on CPU.
- [Note Queue Reconciler](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/note-queue-reconciler) · [page](https://coreyjames.ai/agents/specialists/note-queue-reconciler/): Checks that every queued note reached storage, flags stragglers past a grace period, and records a summary.
