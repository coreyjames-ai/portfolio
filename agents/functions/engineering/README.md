# Engineering

**Planning, building, reviewing and releasing software, with the reasoning kept.**

Canonical: https://coreyjames.ai/agents/functions/engineering/  
Author: Corey James · Published: 2026-11-11 · Kind: agent function  

## The roles

- [The Software Department](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/software-department) · [page](https://coreyjames.ai/agents/roles/software-department/): For a founder with a large build and a small team.
- [The Ticket Clearer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/ticket-clearer) · [page](https://coreyjames.ai/agents/roles/ticket-clearer/): For an engineering manager with a queue of small tickets.
- [The Programme Office](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/programme-office) · [page](https://coreyjames.ai/agents/roles/programme-office/): For a programme manager with several projects in flight.
- [The Second Opinion](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/second-opinion) · [page](https://coreyjames.ai/agents/roles/second-opinion/): For a CTO who wants a critical system read by someone who did not build it.
- [The Change Board](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/change-board) · [page](https://coreyjames.ai/agents/roles/change-board/): For a manager about to approve a risky change.
- [The Due-Diligence Analyst](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/due-diligence-analyst) · [page](https://coreyjames.ai/agents/roles/due-diligence-analyst/): For a CTO inheriting or acquiring a codebase.
- [The Integration Engineer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/integration-engineer) · [page](https://coreyjames.ai/agents/roles/integration-engineer/): For an IT lead who keeps being asked to connect another service.
- [The Automation Builder](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/automation-builder) · [page](https://coreyjames.ai/agents/roles/automation-builder/): For a manager with recurring jobs done by hand.
- [The Record Keeper](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/record-keeper) · [page](https://coreyjames.ai/agents/roles/record-keeper/): For whoever owns a system now.
- [The Contractor Pass](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/contractor-pass) · [page](https://coreyjames.ai/agents/roles/contractor-pass/): For a team that wants outside or automated contributors without handing over the keys.
- [The Migration Planner](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/migration-planner) · [page](https://coreyjames.ai/agents/roles/migration-planner/): For an engineering lead who just read a vendor's deprecation notice.
- [The Incident Commander](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/incident-commander) · [page](https://coreyjames.ai/agents/roles/incident-commander/): For an engineering manager in the middle of a messy incident.
- [The Follow-Through Engineer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/follow-through-engineer) · [page](https://coreyjames.ai/agents/roles/follow-through-engineer/): For an engineering manager walking out of a design meeting.
- [The Handbook Keeper](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/handbook-keeper) · [page](https://coreyjames.ai/agents/roles/handbook-keeper/): For an operations lead whose team runs on a written playbook.
- [The Research Desk](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/research-desk) · [page](https://coreyjames.ai/agents/roles/research-desk/): For anyone with a question that needs digging.
- [The Systems Bridge](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/systems-bridge) · [page](https://coreyjames.ai/agents/roles/systems-bridge/): For an operations lead whose processes span several apps.
- [The Review Panel](https://github.com/coreyjames-ai/portfolio/tree/main/agents/roles/review-panel) · [page](https://coreyjames.ai/agents/roles/review-panel/): For a tech lead who wants every change read by more than one specialist.

## Specialists these roles share

- [Code Impact Analyst](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/code-impact-analyst) · [page](https://coreyjames.ai/agents/specialists/code-impact-analyst/): For every function or type a change touches, it lists what calls it and what it calls up to three steps out.
- [Code Reviewer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/code-reviewer) · [page](https://coreyjames.ai/agents/specialists/code-reviewer/): Reviews finished code and reports against the plan, lists what is missing, extra or wrong with file and line, freezes the list after the first pass and then checks only the fixes.
- [Documentation Site Harvester](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/documentation-site-harvester) · [page](https://coreyjames.ai/agents/specialists/documentation-site-harvester/): Crawls a documentation website inside set domain and path boundaries, cleans each page into readable text, splits it into sections, writes a summary, keywords and a quality score for each section, and makes the whole site searchable.
- [Regression Historian](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/regression-historian) · [page](https://coreyjames.ai/agents/specialists/regression-historian/): Given a broken function or an error, works out which pieces of work touched that area and in what order, who calls it now, and how the failure travels through the code.
- [API Upgrade Planner](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/api-upgrade-planner) · [page](https://coreyjames.ai/agents/specialists/api-upgrade-planner/): Reads the documentation for the new version, finds every place the old interface is used, sizes the change, and drafts the task plan for the upgrade.
- [Acceptance Checker](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/acceptance-checker) · [page](https://coreyjames.ai/agents/specialists/acceptance-checker/): Checks the facts of the finished work against each acceptance point, refuses claims that are only narrative, and either signs the item off or returns a precise fix list.
- [Acceptance Tester](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/acceptance-tester) · [page](https://coreyjames.ai/agents/specialists/acceptance-tester/): Before new code joins the product, this agent runs the acceptance checks and refuses anything that contains placeholder code or skipped steps.
- [Architecture Reviewer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/architecture-reviewer) · [page](https://coreyjames.ai/agents/specialists/architecture-reviewer/): Reads a proposed change for how it fits the existing design and writes its findings on the ticket.
- [Build and Test Runner](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/build-and-test-runner) · [page](https://coreyjames.ai/agents/specialists/build-and-test-runner/): Runs a compile check and the test suite in order, stops at the first failure and checks the service health endpoint afterwards.
- [Change Impact Reviewer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/change-impact-reviewer) · [page](https://coreyjames.ai/agents/specialists/change-impact-reviewer/): Maps everything a proposed change touches before anyone approves it and posts the impact summary on the merge request.
- [Code-Grounded Reviewer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/code-grounded-reviewer) · [page](https://coreyjames.ai/agents/specialists/code-grounded-reviewer/): Reviews a team's claims about finished work with search access limited to that system's code, so every finding points to a file and line.
- [Credential-Free Contributor](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/credential-free-contributor) · [page](https://coreyjames.ai/agents/specialists/credential-free-contributor/): Clones a repository, makes and tests a change on its own branch and asks a trusted steward to open the merge request, never holding the repository key itself.
- [Dead Code Finder](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/dead-code-finder) · [page](https://coreyjames.ai/agents/specialists/dead-code-finder/): Lists functions and types that nothing appears to call, as candidates for a person to review.
- [Decision Recorder](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/decision-recorder) · [page](https://coreyjames.ai/agents/specialists/decision-recorder/): Watches the team's decisions log and working notes folder.
- [Documentation Drift Auditor](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/documentation-drift-auditor) · [page](https://coreyjames.ai/agents/specialists/documentation-drift-auditor/): Compares what internal documents say with what the code actually does and lists each mismatch with the document section and the file and line.
- [Documentation Reviewer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/documentation-reviewer) · [page](https://coreyjames.ai/agents/specialists/documentation-reviewer/): Checks that the documentation for a change matches what the code now does and lists what is missing.
- [Event Delivery Watchdog](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/event-delivery-watchdog) · [page](https://coreyjames.ai/agents/specialists/event-delivery-watchdog/): It checks that social, email and payment notifications are still arriving and that usage allowances are not running out, and it alerts the team when something drops.
- [Independent Code Auditor](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/independent-code-auditor) · [page](https://coreyjames.ai/agents/specialists/independent-code-auditor/): Audits a running system read-only in parallel tracks (interfaces, storage, runtime and deployment, test honesty) and reports every finding with file, line and severity against what the documentation claims.
- [Independent Review Clerk](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/independent-review-clerk) · [page](https://coreyjames.ai/agents/specialists/independent-review-clerk/): It matches the verdict to the review that was requested and releases or holds the project exactly once.
- [Integration Health Checker](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/integration-health-checker) · [page](https://coreyjames.ai/agents/specialists/integration-health-checker/): This agent runs the standard checks across the integration platform so a broken connection is found before a user finds it.
- [Issue Change Watcher](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/issue-change-watcher) · [page](https://coreyjames.ai/agents/specialists/issue-change-watcher/): It reports what changed since the last check.
- [Issue Review Panel](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/issue-review-panel) · [page](https://coreyjames.ai/agents/specialists/issue-review-panel/): It assigns AI advisors distinct roles (mediator, technical expert, security auditor, devil's advocate, referee, pragmatist and innovator), has them review an issue together, and follows the issue for changes.
- [Performance Reviewer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/performance-reviewer) · [page](https://coreyjames.ai/agents/specialists/performance-reviewer/): Reads a change for slow paths and wasted work and reports them on the ticket with the lines concerned.
- [Plan Deliberation Panel](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/plan-deliberation-panel) · [page](https://coreyjames.ai/agents/specialists/plan-deliberation-panel/): Puts several models from different vendors in one structured debate that works through numbered plan revisions and ends only when all agree, then hands over a plan ready to execute.
- [Platform Capability Reviewer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/platform-capability-reviewer) · [page](https://coreyjames.ai/agents/specialists/platform-capability-reviewer/): This agent compares what the platform's control layer and GPU servers can actually do with what the plans say, and closes each build stage with a written review.
- [Project Closer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/project-closer) · [page](https://coreyjames.ai/agents/specialists/project-closer/): Closes a project, phase or program only when every required item carries a current sign-off, writes the closing summary with cost, archives the team and retires everything it opened.
- [Project Planning Clerk](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/project-planning-clerk) · [page](https://coreyjames.ai/agents/specialists/project-planning-clerk/): It turns what you want done into a fully specified plan grounded in the real code and project, checks it before anyone begins, records the facts it relied on with two independent checks, and handles approved changes to a plan already under way.
- [Quality Fix Coordinator](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/quality-fix-coordinator) · [page](https://coreyjames.ai/agents/specialists/quality-fix-coordinator/): It records what must be fixed against each failed criterion, assigns the fix, and sends the work back for review.
- [Red Team Reviewer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/red-team-reviewer) · [page](https://coreyjames.ai/agents/specialists/red-team-reviewer/): Attacks every major decision and every change of scope from a different model family than the builders, looking for the assumption that breaks, and holds approval until it has answered.
- [Repository Assistant](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/repository-assistant) · [page](https://coreyjames.ai/agents/specialists/repository-assistant/): This agent keeps tickets, comments, branches and merge requests in order so developers spend their time on the code.
- [Repository Steward](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/repository-steward) · [page](https://coreyjames.ai/agents/specialists/repository-steward/): Holds the repository keys, checks who is asking and what branch they offer, opens merge requests for human review and keeps issues, comments and labels in order.
- [Scope Change Manager](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/scope-change-manager) · [page](https://coreyjames.ai/agents/specialists/scope-change-manager/): Handles a mid-project change from proposal to approval: it maps what the change touches, gets an architect's proposal, an independent ruling and a hostile second look, then folds the approved change into the live plan.
- [Software Developer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/software-developer) · [page](https://coreyjames.ai/agents/specialists/software-developer/): Takes one assigned task, reads the brief and the code around it, writes and tests the change inside its allowed folders, submits evidence for each acceptance point and fixes what reviewers send back.
- [Supplier Support Liaison](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/supplier-support-liaison) · [page](https://coreyjames.ai/agents/specialists/supplier-support-liaison/): Writes up the unexplained problem with its evidence, raises it with the supplier's support, follows the case and reports the answer.
- [System Historian](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/system-historian) · [page](https://coreyjames.ai/agents/specialists/system-historian/): Reconstructs a system's story, covering the decisions that shaped it, the changes made, the problems hit and how each was fixed, and the trade-offs accepted, in time order.
- [Systems Connection Specialist](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/systems-connection-specialist) · [page](https://coreyjames.ai/agents/specialists/systems-connection-specialist/): It sets up the connection, issues and rotates its access key, configures the sending system, confirms events arrive, and switches the connection off when it is no longer needed.
- [Technical Due-diligence Researcher](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/technical-due-diligence-researcher) · [page](https://coreyjames.ai/agents/specialists/technical-due-diligence-researcher/): It surveys a large codebase without changing it and writes structured findings, a source list, open questions and an area report for each part of the estate.
- [Test Coverage Reviewer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/test-coverage-reviewer) · [page](https://coreyjames.ai/agents/specialists/test-coverage-reviewer/): Checks whether a change comes with tests for the cases that matter and names the cases left untested.
- [Third-Party Integration Researcher](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/third-party-integration-researcher) · [page](https://coreyjames.ai/agents/specialists/third-party-integration-researcher/): Reads the outside platform's documentation and development-kit source, compares it with the current code and writes down the facts the developers will build on.
- [Ticket-to-Fix Engineer](https://github.com/coreyjames-ai/portfolio/tree/main/agents/specialists/ticket-to-fix-engineer) · [page](https://coreyjames.ai/agents/specialists/ticket-to-fix-engineer/): This agent picks up a new ticket, makes the change, checks it, opens a merge request and leaves a note on the ticket so the requester knows it is ready for review.
